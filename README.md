# Neptune 4 Telegram Bot

Telegram-бот для управления 3D-принтером Neptune 4 через Moonraker/Klipper.
Бот рассчитан на личное использование: он показывает состояние принтера,
температуры, фото с камеры, умеет включать прогрев, отключать нагреватели,
отменять печать, следить за печатью и управлять питанием через домашний сервер.

Основной фокус проекта - быстро получить нужное действие из Telegram без
перехода в веб-интерфейс принтера.

## Как устроен бот

В проекте две основные части:

- `bot.py` - Telegram-слой: меню, команды, обработчики сообщений, фоновые задачи.
- `printer.py` - слой общения с принтером: запросы в Moonraker, G-code-команды,
  чтение температур, статусов и фото.

При запуске бот создаёт один экземпляр `PrinterAPI` и кладёт его в
`application.bot_data`. Этот объект держит общую `aiohttp.ClientSession`, которая
используется всеми обработчиками и закрывается при остановке приложения.

Доступ к принтеру идёт через `PRINTER_URL`. Если перед принтером стоит
Cloudflare Access, бот добавляет заголовки:

- `CF-Access-Client-Id`
- `CF-Access-Client-Secret`

## Главное меню

После `/start` бот показывает постоянную Telegram-клавиатуру:

```text
Состояние принтера | Состояние печати
Режим печати       | Фото
Прогрев            | Температуры
Включить           | Выключить
```

### Состояние принтера

Кнопка одновременно запрашивает две группы данных:

- состояние Klippy через `/printer/info`
- состояние оборудования через `/machine/proc_stats`

Ответ содержит:

- состояние Klippy
- загрузку процессора
- температуру процессора
- троттлинг
- загрузку ОЗУ

Запросы выполняются параллельно через `asyncio.gather`, поэтому кнопка не ждёт
их строго по очереди.

### Состояние печати

Бот читает объекты Moonraker:

- `webhooks`
- `virtual_sdcard`
- `print_stats`

Дальше ответ зависит от состояния:

- если Klippy не готов, бот показывает сообщение `webhooks`
- если принтер в ожидании, отвечает `Принтер в ожидании`
- если печать завершена, показывает имя файла
- если печать идёт или стоит на паузе, показывает имя файла, прогресс и
  оставшееся время

Оставшееся время считается через прогресс `virtual_sdcard.progress` и
`estimated_time` из `/server/files/metadata`.

### Режим печати

`Режим печати` включает фоновую проверку состояния печати каждые 15 секунд.

Логика такая:

- пока состояние `printing`, бот молчит
- если печать перешла в `paused`, бот один раз сообщает о паузе
- если печать завершилась, остановилась или ушла в ошибку, бот отправляет
  сообщение и выключает фоновую проверку
- если принтер стал недоступен, бот сообщает об этом и тоже выключает проверку

Для одного чата одновременно запускается только один мониторинг. Если нажать
кнопку повторно, бот не создаст второй job.

### Фото

Бот берёт снимок с:

```text
/webcam/?action=snapshot
```

После получения изображение разворачивается на 180 градусов и отправляется в
Telegram как фото.

### Прогрев

Кнопка `Прогрев` выставляет целевые температуры:

- экструдер: `240°C`
- основная зона стола: `80°C`
- внешняя зона стола: `80°C`

Для этого отправляется G-code через `/printer/gcode/script`:

```gcode
SET_HEATER_TEMPERATURE HEATER=extruder TARGET=240
SET_HEATER_TEMPERATURE HEATER=heater_bed TARGET=80
SET_HEATER_TEMPERATURE HEATER=heater_bed_outer TARGET=80
```

Внешняя зона стола настроена в Klipper как `heater_generic heater_bed_outer`,
а в команде используется имя heater'а `heater_bed_outer`.

### Температуры

Кнопка показывает текущую температуру, цель и мощность нагрева для:

- экструдера
- основной зоны стола
- внешней зоны стола

Читаемые объекты Moonraker:

- `extruder`
- `heater_bed`
- `heater_generic heater_bed_outer`

### Выключить

Кнопка `Выключить` не выполняет действие сразу. Она показывает временное
сообщение с командами:

```text
Чтобы отключить нагрев, введите /heaters_off

Чтобы отменить печать, введите /cancel_printing

Чтобы выключить принтер, введите /poweroff
```

Через 10 секунд это сообщение удаляется ботом. Это сделано, чтобы опасные
действия не висели в чате постоянно и не были случайно нажаты из старой
переписки.

После ввода `/poweroff`, `/heaters_off` или `/cancel_printing` бот удаляет
сообщение пользователя с командой. В чате остаётся только ответ с результатом действия.

### Включить

Кнопка сначала проверяет доступность принтера через `/printer/info`.

Если принтер уже доступен, бот отвечает `Принтер включен.` и ничего больше не
делает.

Если принтер недоступен, бот подключается по SSH к домашнему серверу и запускает
скрипт включения розетки:

```bash
cd ~/printer_power && .venv/bin/python tapo.py
```

## Команды

### `/poweroff`

Команда выключает принтер в два этапа:

1. Проверяет, что принтер доступен через `/printer/info`.
2. Подключается по SSH к домашнему серверу.
3. Запускает выключение принтера.
4. Ждёт 15 секунд.
5. Выключает розетку.

Команды на домашнем сервере:

```bash
cd ~/printer_power && .venv/bin/python printer.py
cd ~/printer_power && .venv/bin/python tapo.py
```

Если принтер недоступен, бот не выключает питание и отвечает:

```text
Нет соединения с принтером. Не выключаю.
```

### `/heaters_off`

Отключает все нагреватели через G-code:

```gcode
TURN_OFF_HEATERS
```

Это штатная Klipper-команда, поэтому она выключает все настроенные нагреватели,
а не только те, которые явно используются в меню температур.

### `/cancel_printing`

Отменяет текущую печать через Moonraker:

```text
POST /printer/print/cancel
```

Перед отменой бот проверяет состояние печати. Если принтер не в состояниях
`printing` или `paused`, команда не отправляется, а бот отвечает:

```text
Сейчас ничего не печатается.
```

Это важно, потому что cancel endpoint может выполнить пользовательский
cancel-макрос даже тогда, когда печати нет.

Если отмена прошла успешно и был включён `Режим печати`, бот останавливает
фоновый мониторинг, чтобы не прислать лишнее сообщение о завершении.

## Доступ и безопасность

Если задан `TELEGRAM_CHAT_IDS`, бот принимает сообщения только от перечисленных
чатов. Все остальные получают:

```text
Доступ запрещен
```

Опасные действия не вынесены в обычные кнопки напрямую:

- выключение принтера выполняется только командой `/poweroff`
- отмена печати выполняется только командой `/cancel_printing`
- отключение нагрева выполняется только командой `/heaters_off`

Кнопка `Выключить` лишь временно показывает список этих команд.

Сообщения пользователя с этими командами удаляются сразу после получения, чтобы они не оставались в истории чата.

## Переменные окружения

Минимальный набор `.env`:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_IDS=

PRINTER_URL=

CLOUDFLARE_AC_ID=
CLOUDFLARE_AC_SECRET=

HOME_SERVER_HOSTNAME=
HOME_SERVER_USER=
HOME_SERVER_PASSWORD=
```

Описание:

- `TELEGRAM_BOT_TOKEN` - токен Telegram-бота.
- `TELEGRAM_CHAT_IDS` - список разрешённых chat id через запятую.
- `PRINTER_URL` - адрес Moonraker/принтера.
- `CLOUDFLARE_AC_ID` и `CLOUDFLARE_AC_SECRET` - сервисные заголовки Cloudflare
  Access, если принтер закрыт через Cloudflare.
- `HOME_SERVER_HOSTNAME`, `HOME_SERVER_USER`, `HOME_SERVER_PASSWORD` - SSH-доступ
  к серверу, который управляет питанием принтера.

## Локальный запуск

Через Poetry:

```bash
poetry install
poetry run python bot.py
```

Через Docker Compose:

```bash
docker compose up -d --build
```

`docker-compose.yml` подключает `.env` и перезапускает контейнер с политикой
`unless-stopped`.

## Деплой

В репозитории есть GitHub Actions workflow `.github/workflows/deploy.yml`.

При push в `main` он подключается к серверу по SSH и выполняет:

```bash
cd <PROJECT_FOLDER>
docker compose down --rmi local
git pull
docker compose up -d --build
```

Для workflow нужны GitHub Secrets:

- `HOST`
- `USER`
- `PASSWORD`
- `PROJECT_FOLDER`
